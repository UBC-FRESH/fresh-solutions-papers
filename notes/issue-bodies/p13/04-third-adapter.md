# P13.4: Third adapter and portability

Parent: #81

## Why

Two adapters written by the same author do not establish portability.

## Work

- [ ] Choose a third public problem family.
- [ ] Implement the adapter from the contract, preferably in a separate subagent session.
- [ ] Add a small reference run and exact replay.
- [ ] Record what the engine did not need to change.
- [ ] Update the portability claim.

## Acceptance

- Third adapter works under the same contract.
- Evidence is replayable.
- “Third-party” or “portability” claims are supported or removed.
